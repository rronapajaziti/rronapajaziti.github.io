Selected work

01

Scribe

Speech-to-text evaluation platform · Bachelor's thesis

Upload an audio recording, transcribe it with Google Cloud Speech-to-Text or OpenAI Whisper, and measure how accurate the result is with standard metrics (WER, CER, MER, WIL). It works with Albanian, English, German and Turkish, and the dashboard compares accuracy across languages, dialects, age and gender.

Next.js · TypeScript · Django REST · PostgreSQL · Whisper · Docker

Source on GitHub
02

RecipeLens

Mobile app · iOS, Android and web

Take a photo of a cookbook page or a handwritten recipe card and RecipeLens reads it for you. OCR and a custom parser pre-fill the ingredients and steps, and a short review wizard lets you fix anything before saving. Recipes are organised by category with favourites, search, English and Albanian, and a separate admin panel.

React Native · Expo · Node.js · Express · MongoDB · OCR

03

Hair Salon Management System

Freelance · built for a working salon

The whole salon runs on it: appointments and a calendar, staff and services, client history, discounts, and daily and monthly expenses. Owners get a dashboard with earnings, weekly bookings and their most loyal clients, and each role only sees what it should.

React · Tailwind · ASP.NET Core · MSSQL · JWT auth

04

Motion to Animation

Computer vision experiment

The first step towards driving an animated character with your own body. The script finds 33 pose landmarks in a photo with MediaPipe and draws the skeleton with OpenCV. Drag across the image to compare.

Python · MediaPipe · OpenCV
